# SOFT STREAM NEXUS CARE AI — مختبر الروبوت الذكي لرعاية كبار السن

مختبر تفاعلي ثلاثي الأبعاد (عربي RTL) لتركيب وتوصيل ومحاكاة روبوت رعاية وسوار ذكي مبنيين على ESP32.
**كل البيانات والقراءات في المشروع محاكاة؛ لا يتصل بأي عتاد ولا يرسل بيانات لأي خادم.**

## التشغيل
```bash
npm install
npm run dev        # تطوير
npm run build      # بناء للإنتاج (dist)
npm run typecheck  # فحص الأنواع
npm test           # اختبارات الوحدة (29 اختبارًا)
```
النشر على Vercel: استورد المستودع (Framework: Vite) — الإعداد جاهز في `vercel.json`.

## الصفحات (9)
1. **مختبر التركيب** — 12 مرحلة بمنطق حالة حقيقي؛ لا تكتمل مرحلة تلقائيًا. المرحلة 10 تتطلب اعتماد كل التوصيلات، 11 تتطلب تشغيل المحاكاة، 12 تتطلب تسجيل اختبارات العائق والدواء والسقوط والطوارئ.
2. **مكتبة المكونات** — معاينة ثلاثية الأبعاد ومواصفات؛ التكلفة تقدير يدخله المستخدم وليست سعرًا موثقًا.
3. **توصيلات الدائرة** — أسلاك متحركة من بيانات منظمة، دليل ألوان بنصوص، جدول توصيلات، اعتماد يتطلب مشاهدة الأنيميشن واختيار الوجهة الصحيحة، وفحوص سلامة كهربائية.
4. **محاكاة حركة الروبوت** — حساس مسافة بمخروط ومنطقة خطر، عوائق، سلوك توقف/تفادٍ.
5. **السوار الذكي** — بيانات MPU6050 تركيبية، كاشف سقوط بقواعد شفافة، مهلة إلغاء، زر طوارئ تجريبي.
6. **تذكير الأدوية** — تذكيرات مع صوت/نطق (مع بديل مرئي)؛ «تم الاستلام» لا يعني أن الدواء أُخذ.
7. **Care Twin** — ست حالات (طبيعي / يحتاج مراجعة / اشتباه في سقوط / طوارئ تجريبية / غير متصل / بيانات غير متاحة)؛ غياب النبض لا يُعرض كحالة آمنة.
8. **سجل الأحداث** — تصفية وتصدير JSON ومسح بتأكيد؛ حالات التسليم: محلي / بانتظار الخادم / أقرّه خادم تجريبي / فشل.
9. **إعدادات المشروع** — محرر خريطة الدبابيس مع فحص GPIO، إعدادات كهربائية، تفضيلات، إعادة ضبط.

## دليل التجميع المختصر
اتبع المراحل الاثنتي عشرة داخل المختبر بالترتيب: جرد وسلامة ← هيكل ← محركات وعجلات ← ESP32 ← مشغّل المحركات ← مصدر الطاقة والمنظمات ← حساس المسافة (مع مقسّم ECHO) ← الشاشة والجرس والزر ← توصيل الأسلاك ← اختبار المحاكاة ← السوار ← اختبارات القبول. كل مرحلة فيها لماذا، الخطوات، السلامة، واستكشاف الأخطاء.

## ما هو محاكى وما يحتاج عتادًا
| محاكى في البرنامج | يحتاج عتادًا حقيقيًا |
|---|---|
| حركة الروبوت وقراءة الحساس | برنامج ESP32 الثابت (firmware) |
| بيانات MPU6050 والسقوط | معايرة الحساس واختبار ميداني |
| التسليم للسحابة وحالة الاتصال | خادم وإشعارات حقيقية |
| البطارية والخريطة | قياس فعلي للبطارية وتحديد موقع |

## قيود
- كاشف السقوط قائم على قواعد بسيطة وغير مُثبت سريريًا؛ ليس جهازًا طبيًا ولا بديلًا للرعاية.
- فحوص السلامة الكهربائية إرشادية؛ راجع أوراق بيانات القطع واستخدم قاطعًا/حماية للبطارية.
- مجسّم ثلاثي الأبعاد مرسوم بـ Canvas 2D بدون WebGL (يعمل في كل المتصفحات).
- التقدّم محفوظ في localStorage لهذا المتصفح فقط.
